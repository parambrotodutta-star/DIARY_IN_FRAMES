# Diary in Frames — Minimalist Cinematic Portfolio

A premium, highly responsive single-page web portfolio tailored for filmmakers, cinematographers, and photographers. Built with a focus on deep atmospheric color grading, glassmorphic UI elements, interactive scroll behaviors, and absolute mobile responsiveness.

## ✨ Core Design Features

* **Hills Station Backdrop Overlay:** The `<main>` content area is structurally bound to a fixed background image (`Hills Station.png`), blended with a sophisticated midnight navy gradient tint (`rgba(10, 13, 20, 0.82)`) to elevate layout depth while keeping text perfectly sharp and readable.
* **Premium Dark Palette:** Completely avoids stark white spaces, utilizing deep slate tones to let the cinematic imagery pop naturally.
* **Glassmorphic UI Elements:** Advanced CSS backdrop blur filters apply smooth, frosted glass styling across navigation headers, content cards, and the contact layout.
* **8-Image Metro Grid (Zero-Crop Architecture):** A masonry style mosaic layout featuring your complete asset library. Dynamic grid handling rearranges image structures cleanly depending on desktop or mobile viewports to prevent layout breakages.
* **Native Multi-Format Lightbox:** An integrated safe-viewer that allows users to tap or click any image to focus and scale it comfortably without layout shifts.
