# Diary in Frames — Minimalist Cinematic Portfolio

A premium, highly responsive single-page web portfolio tailored for filmmakers, cinematographers, and photographers. Built with a focus on deep atmospheric color grading, modern UI aesthetics, fluid interactions, and absolute mobile responsiveness.

## ✨ Core Design Features

* **Premium Dark Palette:** Completely avoids stark white spaces, utilizing a sophisticated deep slate (`#0a0d14`) and midnight navy aesthetic to let the images pop naturally.
* **Glassmorphic UI Components:** Implements clean glass-morphism (using advanced CSS backdrop filters) across navigation bars, descriptive structural cards, and contact elements.
* **Apple-Inspired Momentum Scroll Feel:** Leverages custom layout mechanics combined with high-performance CSS transforms to give desktops and mobile displays a smooth, weight-based scrolling sensation.
* **Zero-Crop Mobile Architecture:** Custom grid systems rearrange dynamically using responsive media queries, ensuring typography scales gracefully and imagery never crops awkwardly on narrow viewports.
* **Native Immersive Lightbox:** Built-in safe viewer allowing mobile and desktop users to tap any image to expand it seamlessly without layout shifts.
